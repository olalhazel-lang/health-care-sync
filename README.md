# Health Care Sync

Health Care Sync is a multi-page web application designed to streamline healthcare management for both patients and medical staff. It provides an intuitive, user-friendly interface to manage appointments, patient profiles, and operational logs efficiently.

## Live Demo
Check out the live website here: [Health Care Sync Live](https://olalhazel-lang.github.io/health-care-sync/)

## Built With
* **HTML5** – Structure and layout of all application pages.
* **CSS3** – Custom styling, responsive design, and clean UI layouts.
* **JavaScript (Vanilla)** – DOM manipulation, form handling, and interactive features.

## Project Structure

health-care-sync/
│
├── index.html        # Landing / Dashboard page
├── schedule.html     # Appointment scheduler view
├── Patients.html     # Patient profile management form
├── logs.html         # Data logs view
